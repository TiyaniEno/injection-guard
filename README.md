# injection-guard
Industrial WAF middleware for Python. Stops OS command injection attacks.

Blocks attacks like:
- `; ls -la`
- `&& cat /etc/passwd`
- `| whoami`
- `$(id)`

## Install

```bash
pip install injection-guard-waf
